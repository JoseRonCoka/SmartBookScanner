# Smart Book Scanner 

Book store order submission and processing application. 

## About
Developed an Android app in Java replacing barcode scanners with mobile camera scanning to speed up bookstore order processing.
Integrated Firebase Realtime Database with user authentication, order history, and inventory management features.
The project was created as a Capstone Project for NSU.
You can contact me with any questions on: joseluisroncoka@hotmail.com

## Features
- Camera Scanner
- Order submission and processing.
- Order history
- Book Database, including book information and inventory
- User Authentication 

## Tech Stack
- Android Studio    
- Java
- Firebase Realtime Database
- JourneyApps Zxing-android-embedded, https://github.com/journeyapps/zxing-android-embedded, for the book's barcode scanner implementation.
